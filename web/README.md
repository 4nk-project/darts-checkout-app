# ダーツチェックアウト練習 Web版

HTML、CSS、JavaScriptだけで動く静的Webアプリです。

## ローカルで開く

`web/index.html` をブラウザで開くだけで動きます。

## GitHub Pagesで公開する

1. GitHubにリポジトリをpushする
2. GitHubのリポジトリ設定を開く
3. `Settings` → `Pages`
4. `Build and deployment` のSourceを `Deploy from a branch` にする
5. Branchを `main`、Folderを `/web` にする
6. `Save`

数分後にGitHub PagesのURLが発行されます。

## 機能

- ソフトダーツのチェックアウト問題
- ダーツ盤タップ入力
- 難易度選択
- 答え表示
- 成績表示
- アレンジ表
- プライバシー/ライセンス表示
