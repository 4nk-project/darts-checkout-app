# ダーツチェックアウト練習

ソフトダーツのチェックアウトを、計算問題のように練習するAndroidアプリです。

## できること

- チェックアウト可能な残り点を難易度別にランダム出題
- ダーツ盤をタップして最大3投で回答
- ソフトダーツ向けにBULLは50点として判定
- 合計点と最後のダブル・トリプル・BULL条件で正誤判定
- 入力の取り消し、クリア、答えを見る、次の問題
- 成績表示
- アレンジ表、プライバシー説明、ライセンス説明

## APKのインストール

最新版のAPKはGitHub Releasesから配布する想定です。

1. このリポジトリの `Releases` を開く
2. 最新版の `app-release.apk` をダウンロード
3. Android端末でAPKを開く
4. 必要に応じて「不明なアプリのインストール」を許可する
5. インストールする

Google Play外で配布されるAPKのため、インストール時にAndroidの警告が表示される場合があります。

## 開発環境での実行

1. Android Studioでこのフォルダを開く
2. Gradle Syncを実行する
3. エミュレーターまたはAndroid端末でRunする

コマンドラインでDebug APKを作る場合:

```sh
./gradlew assembleDebug
```

## Release APKの作成

Android Studioで以下を実行します。

1. `Build`
2. `Generate Signed App Bundle / APK`
3. `APK` を選択
4. 署名キーを作成または選択
5. `release` を選択
6. `Finish`

生成されたAPKをGitHub Releasesへアップロードします。

重要:

- `.jks` などの署名キーは絶対にGitHubへコミットしないでください
- 署名キーを失うと、同じアプリとしてアップデートできなくなります
- 配布用にはdebug APKではなくrelease APKを使ってください

## プライバシー

このアプリは個人情報を収集しません。練習中の成績はアプリ画面内でのみ使用します。問い合わせメールを送る場合は、メールアプリ側で入力した内容が送信されます。
